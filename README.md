# Pocket Chef — политика конфиденциальности

Служебный сайт с политикой конфиденциальности мобильного приложения
Pocket Chef, которое входит в единый кулинарный проект L'atelier / Pocket Chef.

Опубликованная политика: [valorin777.github.io/pocketchef-privacy/](https://valorin777.github.io/pocketchef-privacy/).

## Содержимое

- `index.html` — текст политики конфиденциальности, опубликованный через GitHub Pages.
- `README.md` — описание назначения этого репозитория и его связи с проектом.

GitHub Pages публикует сайт из корня ветки `main`.

## Один проект, разные реализации

L'atelier и Pocket Chef — один кулинарный проект. Его репозитории содержат
разные реализации и служебный сайт:

| Репозиторий | Назначение |
| --- | --- |
| [latelier](https://github.com/Valorin777/latelier) | Веб-версия: PWA, Telegram Mini App и API на FastAPI |
| [pocket-chef](https://github.com/Valorin777/pocket-chef) | Офлайн-приложение для iOS и Android на Capacitor |
| [latelier-ai-platform](https://github.com/Valorin777/latelier-ai-platform) | Ранняя веб-реализация на HTML/JS и FastAPI |
| [pocketchef-privacy](https://github.com/Valorin777/pocketchef-privacy) | Сайт политики конфиденциальности мобильного Pocket Chef |
